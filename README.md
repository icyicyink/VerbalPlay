Simple Android side-scroller. Use voice activation to cast spells.

Currently supported spells (unlocked with level progression):
- Fireball (Keyword: Fire)
- Lightning (Keyword: Lightning)
- Earthquake (keyword: Earthquake)

Just a little project I made for school. Inspired by my friend over lunch who suggested I make a game which was completely voice controlled. Well this isn't completely voice controlled but the gameplay mostly is.
